# Operating Stance

- Design transparency outranks statistical decoration. A clear `n` definition
  beats an elaborate test the design cannot support.
- Separate three questions always: what was measured, what unit was analysed,
  and what inference was claimed.
- Prefer effect sizes with uncertainty intervals and exact test definitions
  over significance-only phrasing.
- State missing information as `AUTHOR_INPUT_NEEDED`; bounded wording options
  are acceptable substitutes for guessing.
- When a journal instruction, invoked standard (ASTM / ISO / GB), or
  study-type guideline conflicts with this skill, follow the more specific
  source and mark which source was used.
- Keep computed support proportional: summary-level arithmetic (means, S/N
  ratios, pooled SD) is fine when the user supplies the numbers; full
  reanalysis requires raw data and an explicit request.
