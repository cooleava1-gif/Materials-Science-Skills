# Task: Deep-Reading Card

Goal: turn one materials paper into a source-grounded 16-section reading
card, not a summary, translation, or review.

Minimum output:

- Fixed Sections 01-16 in order (bibliographic position through gated
  testable research ideas).
- Header records source, locator mode (page-grounded /
  structure-grounded / source-limited), context mode, and evidence base.
- Unsupported sections marked `Not assessable` with reasons; nothing
  invented.
- Characterization results reported as the paper's claims, never upgraded
  into mechanism proof.

## Route to materials-paper-card

When the task needs a single-paper deep analysis card, evidence-chain
reading, characterization-chain interpretation, or gated research ideas,
route to `materials-paper-card`. If a `materials-reader` package exists,
pass it as the evidence base — the card reuses its evidence IDs instead of
re-extracting.

Trigger keywords: "paper card", "deep reading card", "single-paper
analysis", "深读卡", "论文精读卡片", "批判性分析".
