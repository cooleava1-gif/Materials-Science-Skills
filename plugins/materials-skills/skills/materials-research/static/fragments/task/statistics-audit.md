# Task: Statistics Audit

Goal: make the manuscript's statistical reporting defensible before
submission.

Minimum statistics-audit output:

- Claim table: each statistical claim with its test, n, correction, effect
  estimate, uncertainty, and software.
- Independent-unit readout: specimens vs repeated readings vs nested
  subspecimens, per comparison.
- P0/P1/P2 issue list with ready-to-paste fixes.
- Reviewer-risk note for the statistics that remain challengeable.

Civil materials statistics rules:

- Three specimens measured five times each is n = 3, not 15 — readings are
  not replicates.
- Name the multiple-comparison procedure whenever pairwise stars appear.
- Taguchi ANOVA needs a stated error term; an additive-model optimum is a
  prediction until the confirmation run exists.
- SEM, SD, and CI must be declared per figure; captions and Methods must
  agree on n.

## Route to materials-statistics

When the task requires auditing, revising, or drafting statistical reporting
— replicate definitions, design-matched tests (ANOVA / Taguchi S/N / RSM /
mixture), multiple-comparison corrections, effect sizes with uncertainty,
figure-statistics alignment, or reviewer comments about statistics — route
to `materials-statistics`.
